 6. Практические заметки 
 Денежный баланс лицевого счёта: True API /elk/product-groups/balance/all и /elk/product-groups/balance. Нужен True API Bearer token, не SUZ clientToken. 
 Для БАД ранее использовался productGroupId=17; productGroup в SUZ/OMS — bio. 
 / warehouse / balance и / api / v 2/ wh / balance — складской/товарный баланс, не денежный лицевой счёт. 
 Для обычного True API token используется /auth/simpleSignIn без omsConnection; для SUZ clientToken — /auth/simpleSignIn/{omsConnection}.
