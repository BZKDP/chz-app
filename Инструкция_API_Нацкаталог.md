# Как получить данные о товарах (штрих-коды, названия, атрибуты) из «Честного знака» по API

## Главное
Данные о товарах лежат в **Национальном каталоге** ЧЗ и берутся по **apikey** — это обычная строка-ключ.
**ЭЦП и подписывающий компьютер для этого НЕ нужны.** Достаточно ключа и обычных GET-запросов.

## Твой ключ
```
apikey = <ВСТАВИТЬ_КЛЮЧ>
```
> Ключ берётся в ЛК Национального каталога: **Профиль → «Данные участника» → поле «API KEY»**
> (поле видно только под ролью **Администратор**). Ключ привязан к организации (ИНН) и открывает её карточки.

## Адрес API
- Прод: `https://апи.национальный-каталог.рф`
- Тест: `https://api.nk.sandbox.crptech.ru`

Авторизация — просто добавляешь `?apikey=КЛЮЧ` в запрос. Ничего дополнительно скачивать/настраивать не надо.

## Что вызывать (GET-запросы)

**1. Список всех карточек товаров (штрих-коды + названия):**
```
GET https://апи.национальный-каталог.рф/v4/product-list?apikey=КЛЮЧ&limit=1000&offset=0
```
Ответ: `{ "total": N, "goods": [ { "good_id":..., "gtin":"04627174095012", "good_name":"...", ... }, ... ] }`
`gtin` — это и есть штрих-код товара (14 цифр). Пагинация через `limit`/`offset` (до 10000 записей).

**2. Полная карточка одного товара по GTIN:**
```
GET https://апи.национальный-каталог.рф/v3/product?apikey=КЛЮЧ&gtin=04627174095012
```
Возвращает всё: название, бренд, категорию, атрибуты, картинки, разрешительные документы.

**3. Краткая карточка (быстрее, меньше данных):**
```
GET https://апи.национальный-каталог.рф/v3/short-product?apikey=КЛЮЧ&gtin=04627174095012
```

**4. Список всех GTIN одного владельца (с хешами для контроля изменений):**
```
GET https://апи.национальный-каталог.рф/v3/etagslist?apikey=КЛЮЧ
```

## Ответ и формат
- По умолчанию JSON. Можно `&format=xml`.
- Штрих-коды (GTIN), названия и атрибуты приходят прямо в ответе — отдельно ничего качать не нужно.
- Лимит запросов на организацию: при исчерпании новая серия — через 5 минут. Текущий расход показывается в заголовке ответа `API-Usage-Limit` (напр. `1/500`).

## Пример (curl)
```bash
curl "https://апи.национальный-каталог.рф/v4/product-list?apikey=КЛЮЧ&limit=100&offset=0"
```

## Пример (Python)
```python
import requests
KEY = "ВСТАВИТЬ_КЛЮЧ"
r = requests.get("https://апи.национальный-каталог.рф/v4/product-list",
                 params={"apikey": KEY, "limit": 1000, "offset": 0})
data = r.json()
for g in data.get("goods", []):
    print(g.get("gtin"), "-", g.get("good_name"))
```

## Частые вопросы
- **«Мне просто подключиться или ещё что-то скачивать?»** — Просто подключаешься по apikey и дёргаешь методы выше. Ничего заранее скачивать не нужно.
- **Нужна ли ЭЦП / токен?** — Нет. apikey заменяет и подпись, и токен. (Альтернатива — токен ГИС МТ в `Authorization: Bearer <token>`, но он живёт ~10 часов и требует подписи; по apikey проще.)
- **Ключ не показывается в ЛК** — значит у пользователя нет роли «Администратор» в ЛК Национального каталога; надо зайти под администратором организации.
- **Ошибка 401 «Не авторизован»** — не передан или неверный apikey.
