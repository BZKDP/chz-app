# chz-app

Локальное приложение для работы с маркировкой «Честный Знак» (товарная группа БАД). Заказывает уникальные коды маркировки (КМ) в СУЗ-ОБЛАКО, печатает их как DataMatrix и ведёт жизненный цикл кода от заказа до вывода из оборота.

## Возможности

- Заказ КМ через API СУЗ (СУЗ-ОБЛАКО, контур ГИС МТ).
- Генерация DataMatrix по полученным кодам (bwip-js) и формирование этикеток/PDF (pdfkit).
- Ввод в оборот и вывод из оборота через True API (документы LP_INTRODUCE_GOODS, отчёты о нанесении и выбытии).
- Подпись запросов УКЭП по ГОСТ (CryptoPro `csptest`) на отдельном компьютере с сертификатом — локально или по SSH.
- Проверка баланса лицевого счёта и расчёт стоимости заказа.
- Импорт карточек товаров из Национального каталога по apikey.
- Необязательный шлюз-очередь для интеграции с внешним сайтом сборки и отдельный веб-кабинет сотрудника (`remote-site/`).

## Стек

Node.js, Express, bwip-js, pdfkit. Хранилище — JSON-файл в `data/`.

## Запуск

```bash
npm install
cp .env.example .env            # заполнить значения; либо data/config.local.json (см. .example)
npm start                       # сервер на http://127.0.0.1:3030
npm test                        # тесты (node --test)
```

Все идентификаторы интеграции и реквизиты задаются через переменные окружения или `data/config.local.json`. Список ключей — в [.env.example](.env.example).

## Требования

Для реальной работы нужны действующие доступы «Честного Знака» (зарегистрированное подключение СУЗ/omsConnection, товарная группа, ИНН организации) и УКЭП с установленным CryptoPro на подписывающем компьютере. Без них приложение не сможет получить токен и заказать коды. Заказ кодов платный и необратимый — проверяйте количество, GTIN и даты партии перед отправкой.
